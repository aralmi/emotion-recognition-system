# Intelligent Emotion Recognition System (IRES)

Веб-приложение для распознавания эмоционального состояния человека по фотографиям и видеопотоку. Были разработаны, обучены и сравнены две независимые модели на основе глубокого обучения: собственная архитектура CNN и трансфер-обучение на базе VGG16.

## Описание проекта

Приложение позволяет пользователю загрузить изображение с лицом или использовать видеопоток с веб-камеры, после чего модель анализирует его и определяет одну из семи эмоций: гнев, отвращение, страх, радость, грусть, удивление или нейтральная. Для демонстрации работы используется веб-интерфейс, созданный с помощью Streamlit. Система позволяет прямое сравнение производительности двух независимых архитектур на одних и тех же данных.

## Основные возможности

*   **Распознавание эмоций в реальном времени:** анализ изображений с использованием веб-камеры с детектором лиц на основе каскадов Хаара (Haar Cascades)
*   **Анализ одиночной фотографии:** загрузка изображения с выводом предсказанной эмоции, точности и распределения вероятностей по всем семи классам
*   **Пакетная обработка:** загрузка нескольких изображений одновременно с выводом статистики и визуализацией результатов

### Две модели для детального сравнения:

*   **Custom CNN:** собственная архитектура сверточной нейронной сети, специализированная для этой задачи
*   **VGG16:** модель на основе архитектуры VGG16, предварительно обученной на ImageNet, с адаптированным классификатором
*   **Визуализация результатов:** отображение изображений с предсказанной эмоцией, уровнем уверенности и вероятностями для каждого класса
*   **Проверка качества моделей:** ручная разметка изображений, сравнение предсказаний обеих моделей, расчет метрик качества (Accuracy, Precision, Recall, F1-score) и матрица ошибок (Confusion Matrix)
*   **Статистика сессии:** просмотр истории анализа, распределения эмоций, графики и тренды качества между сессиями

## Архитектуры нейронных сетей

### Custom CNN: Собственная специализированная архитектура

Разработана собственная архитектура сверточной нейронной сети, специально оптимизированная для распознавания эмоций на небольших изображениях размером 48x48 пиксела:

```python
CustomCNN(
  # Сверточный блок 1
  (conv1): Conv2d(1, 64, kernel_size=(3, 3), padding=(1, 1))
  (bn1): BatchNorm2d(64)
  (relu1): ReLU(inplace=True)
  (pool1): MaxPool2d(kernel_size=2, stride=2)
  (dropout1): Dropout(p=0.25)
  
  # Сверточный блок 2
  (conv2): Conv2d(64, 128, kernel_size=(3, 3), padding=(1, 1))
  (bn2): BatchNorm2d(128)
  (relu2): ReLU(inplace=True)
  (pool2): MaxPool2d(kernel_size=2, stride=2)
  (dropout2): Dropout(p=0.25)
  
  # Сверточный блок 3
  (conv3): Conv2d(128, 256, kernel_size=(3, 3), padding=(1, 1))
  (bn3): BatchNorm2d(256)
  (relu3): ReLU(inplace=True)
  (pool3): MaxPool2d(kernel_size=2, stride=2)
  (dropout3): Dropout(p=0.25)
  
  # Полносвязный слой 1: 6144 входов (256 фильтров * 6 * 6)
  (fc1): Linear(in_features=6144, out_features=512)
  (fc1_bn): BatchNorm1d(512)
  (fc1_dropout): Dropout(p=0.5)
  
  # Полносвязный слой 2
  (fc2): Linear(in_features=512, out_features=256)
  (fc2_bn): BatchNorm1d(256)
  (fc2_dropout): Dropout(p=0.5)
  
  # Выходной слой: 7 классов эмоций
  (fc3): Linear(in_features=256, out_features=7)
)
```

**Характеристики архитектуры:**

*   **Входные данные:** изображения размером 48×48 пиксела в оттенках серого (1 канал)
*   **Сверточная часть:** три блока с прогрессивным увеличением числа фильтров (1→64→128→256)
*   **Каждый блок содержит:** сверточный слой, нормализация батча (BatchNorm2d), активация ReLU, максимальный пулинг и Dropout для регуляризации
*   **Полносвязная часть:** три FC слоя с нормализацией батча между ними и Dropout(0.5)
*   **Всего параметров:** ~7,5 млн
*   **Время инференса:** 10-50 мс на CPU, 5-10 мс на GPU
*   **Оптимизатор:** Adam с learning rate = 0.001
*   **Loss функция:** CrossEntropyLoss
*   **Batch size:** 64
*   **Epochs:** 100-150 с ранней остановкой (early stopping)
*   **Аугментация данных:** случайные повороты, сдвиги, масштабирование

### VGG16: Трансфер-обучение на базе ImageNet

Использование архитектуры VGG16, предварительно обученной на датасете ImageNet, с адаптацией под задачу распознавания эмоций:

```python
VGG16_CustomHead(
  (features): Sequential(
    # Блок 1: 64 фильтра
    Conv2d(3, 64, kernel_size=(3, 3), padding=(1, 1))
    ReLU(inplace=True)
    Conv2d(64, 64, kernel_size=(3, 3), padding=(1, 1))
    ReLU(inplace=True)
    MaxPool2d(kernel_size=2, stride=2)
    
    # Блок 2: 128 фильтров
    Conv2d(64, 128, kernel_size=(3, 3), padding=(1, 1))
    ReLU(inplace=True)
    Conv2d(128, 128, kernel_size=(3, 3), padding=(1, 1))
    ReLU(inplace=True)
    MaxPool2d(kernel_size=2, stride=2)
    
    # Блок 3: 256 фильтров
    Conv2d(128, 256, kernel_size=(3, 3), padding=(1, 1))
    ReLU(inplace=True)
    Conv2d(256, 256, kernel_size=(3, 3), padding=(1, 1))
    ReLU(inplace=True)
    Conv2d(256, 256, kernel_size=(3, 3), padding=(1, 1))
    ReLU(inplace=True)
    MaxPool2d(kernel_size=2, stride=2)
    
    # Блок 4: 512 фильтров
    Conv2d(256, 512, kernel_size=(3, 3), padding=(1, 1))
    ReLU(inplace=True)
    Conv2d(512, 512, kernel_size=(3, 3), padding=(1, 1))
    ReLU(inplace=True)
    Conv2d(512, 512, kernel_size=(3, 3), padding=(1, 1))
    ReLU(inplace=True)
    MaxPool2d(kernel_size=2, stride=2)
    
    # Блок 5: 512 фильтров
    Conv2d(512, 512, kernel_size=(3, 3), padding=(1, 1))
    ReLU(inplace=True)
    Conv2d(512, 512, kernel_size=(3, 3), padding=(1, 1))
    ReLU(inplace=True)
    Conv2d(512, 512, kernel_size=(3, 3), padding=(1, 1))
    ReLU(inplace=True)
    MaxPool2d(kernel_size=2, stride=2)
    
    AdaptiveAvgPool2d((7, 7))
  )
  
  (classifier): Sequential(
    Linear(in_features=25088, out_features=4096)
    ReLU(inplace=True)
    Dropout(p=0.5)
    
    Linear(in_features=4096, out_features=1024)
    ReLU(inplace=True)
    Dropout(p=0.5)
    
    Linear(in_features=1024, out_features=7)  # 7 классов эмоций
  )
)
```

**Характеристики архитектуры:**

*   **Входные данные:** изображения размером 224×224 пиксела в RGB (3 канала)
*   **Сверточная часть:** 16 слоев, организованные в 5 блоков (64→128→256→512→512 фильтров)
*   **Извлечение признаков:** каждый блок использует несколько сверточных слоев для выделения признаков разного уровня абстракции
*   **Получение фиксированного размера:** AdaptiveAvgPool2d(7,7) преобразует выход в размер 7×7
*   **Классификационная "голова" (полностью переделана для нашей задачи):**
    *   FC слой: 25088 → 4096 (фиксация признаков высокого уровня)
    *   FC слой: 4096 → 1024 (промежуточное преобразование)
    *   Выходной FC слой: 1024 → 7 (окончательная классификация по эмоциям)
*   **Dropout(0.5)** между слоями для регуляризации
*   **Всего параметров:** ~138 млн (из них ~128 млн в сверточной части)
*   **Обучаемых параметров:** ~1,5-5 млн (зависит от стратегии разморозки)
*   **Время инференса:** 50-200 мс на CPU, 20-50 мс на GPU
*   **Стратегия обучения:** трансфер-обучение с полной или частичной разморозкой слоев
*   **Оптимизатор:** Adam или SGD с momentum
*   **Learning rate:** 0.0001-0.001 (ниже, чем для Custom CNN)
*   **Batch size:** 32-64
*   **Epochs:** 50-100 (быстрее благодаря предварительному обучению)

## Установка и запуск

1.  **Клонируйте репозиторий**
    ```bash
    git clone https://github.com/aralmi/emotion-recognition-system.git
    cd emotion-recognition-system
    ```
2.  **Создайте и активируйте виртуальное окружение**
    ```bash
    python -m venv venv
    source venv/bin/activate  # Для Windows: venv\Scripts\activate
    ```
3.  **Установите зависимости**
    ```bash
    pip install -r requirements.txt
    ```
4.  **Загрузите обученные модели**

    Обученные модели не хранятся в репозитории из-за их большого размера. Вам необходимо скачать их и поместить в папку `models/`:

    *   `emotion_model_our_architecture.pth` — обученная Custom CNN
    *   `emotion_model_vgg16.pth` — обученная VGG16

5.  **Запустите приложение**
    ```bash
    streamlit run app.py
    ```
    После запуска откройте браузер и перейдите по адресу http://localhost:8501

## Метрики качества

Приложение рассчитывает следующие метрики для оценки производительности моделей:

*   **Accuracy (Точность распознавания):** доля правильных предсказаний от общего количества примеров
*   **Precision (Точность класса):** доля верно предсказанных примеров от всех примеров, предсказанных как этот класс
*   **Recall (Полнота):** доля верно предсказанных примеров этого класса от всех реальных примеров этого класса
*   **F1-score (F1-мера):** гармоническое среднее Precision и Recall для баланса между ними
*   **Confusion Matrix (Матрица ошибок):** визуализация того, какие эмоции модель правильно определяет, а какие путает

Система классифицирует эмоциональное состояние в одну из семи базовых категорий:

*   Гнев (Anger)

*   Страх (Fear)
*   Радость (Happy)
*   Грусть (Sad)
*   Удивление (Surprise)
*   Нейтральная (Neutral)
