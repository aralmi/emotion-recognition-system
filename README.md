# Проект по распознаванию эмоций на основе сверточных нейронных сетей

Этот проект представляет собой веб-приложение для распознавания человеческих эмоций по фотографиям. Были разработаны, обучены и сравнены две модели на основе сверточных нейронных сетей (CNN): кастомная архитектура и модель на основе VGG16.

## 🚀 Описание проекта

Приложение позволяет пользователю загрузить изображение с лицом, после чего модель анализирует его и определяет одну из семи эмоций: гнев, грусть, нейтральная, отвращение, радость, страх или удивление. Для демонстрации работы используется веб-интерфейс, созданный с помощью Streamlit.

## ✨ Основные возможности

-   **Распознавание эмоций в реальном времени**: анализ изображений с помощью веб-камеры.
-   **Загрузка изображений**: возможность загрузить готовый файл для анализа.
-   **Две модели для сравнения**:
    1.  **Custom CNN**: собственная архитектура сверточной нейронной сети.
    2.  **VGG16**: модель на основе известной архитектуры VGG16, дообученная на датасете эмоций.
-   **Визуализация результатов**: отображение изображения с предсказанной эмоцией и вероятностями для каждого класса.

## 🛠️ Технологии

-   **Python 3.12**
-   **PyTorch**: основная библиотека для создания и обучения нейронных сетей.
-   **Streamlit**: для создания интерактивного веб-интерфейса.
-   **OpenCV**: для обработки изображений и работы с веб-камерой.
-   **Pandas & NumPy**: для обработки данных.
-   **Jupyter Notebook**: для исследовательского анализа и обучения моделей.

## 📂 Структура проекта

-   `app.py`: Главный файл приложения Streamlit.
-   `requirements.txt`: Список необходимых библиотек для установки.
-   `train_model.ipynb`: Jupyter-ноутбук с процессом обучения кастомной CNN.
-   `vgg.ipynb`: Jupyter-ноутбук с процессом дообучения модели на основе VGG16.
-   `models/`: Папка для хранения обученных моделей (`.pth`). **(Не входит в репозиторий)**.
-   `assets/`: Папка с примерами изображений для демонстрации работы моделей.
-   `fer2013.csv`: Датасет, использованный для обучения. **(Не входит в репозиторий)**.
-   `README.md`: Документация проекта.

## ⚙️ Установка и запуск

1.  **Клонируйте репозиторий:**
    ```bash
    git clone <ссылка_на_ваш_репозиторий>
    cd <название_папки_проекта>
    ```

2.  **Создайте и активируйте виртуальное окружение:**
    ```bash
    python -m venv venv
    source venv/bin/activate  # Для Windows: venv\Scripts\activate
    ```

3.  **Установите зависимости:**
    ```bash
    pip install -r requirements.txt
    ```

4.  **Загрузите модели:**
    Обученные модели не хранятся в репозитории из-за их большого размера. Вам необходимо скачать их и поместить в папку `models/`:
    -   [Ссылка на `emotion_model_our_architecture.pth`](<вставьте_ссылку_для_скачивания>)
    -   [Ссылка на `emotion_model_vgg16.pth`](<вставьте_ссылку_для_скачивания>)

5.  **Запустите приложение:**
    ```bash
    streamlit run app.py
    ```
    После запуска откройте браузер и перейдите по адресу `http://localhost:8501`.

## 🧠 Обучение моделей

Процесс обучения моделей подробно описан в Jupyter-ноутбуках:
-   `train_model.ipynb`: Обучение собственной CNN с нуля.
-   `vgg.ipynb`: Трансферное обучение (transfer learning) с использованием предобученной модели VGG16.

Для обучения использовался датасет [FER-2013](https://www.kaggle.com/c/challenges-in-representation-learning-facial-expression-recognition-challenge/data), который содержит тысячи изображений лиц с размеченными эмоциями.
